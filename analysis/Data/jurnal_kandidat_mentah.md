## Langkah cek berikutnya (manual, karena halaman resmi memblokir akses)

1. Buka https://www.scimagojr.com dan cek quartile tiap jurnal di atas untuk tahun 2025.
2. Buka halaman "Author guidelines" tiap jurnal untuk APC dan aturan data source.
3. Cek di Scopus Sources list (https://www.scopus.com/sources) untuk status indeks.
4. Cari di Google Scholar paper bibliometrik OpenAlex di jurnal yang masuk shortlist.
